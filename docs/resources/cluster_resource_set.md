# Cluster Resource Set (Resource)

Manifests the ClusterResourceSet controller applies to every cluster `cluster_selector` matches, the way `aws_eks_addon` with a configuration does: a `ClusterResourceSet` on the management cluster the provider block names, with the ConfigMaps (`manifests`) and Secrets (`secrets`) it references created and kept in step by this resource. Two things the controller never does are done here: `prune` deletes objects that leave the set from each matched cluster, and `wait.ready` waits for the applied workloads, CRDs and anything with a `Ready` condition, since the `ClusterResourceSetBinding` only says applied. A manifest may not exceed a ConfigMap's 1 MiB; split it. Import with `namespace/name`.

## Example Usage

```terraform
# A Cilium load-balancer pool for the Tinkerbell Service, applied to one
# cluster once its CNI is up. The manifest becomes a ConfigMap the set
# references; the wait returns when the cluster's binding reports it applied
# and the pool object is Ready.
resource "capi_cluster_resource_set" "lb_pool" {
  name      = "tinkerbell-lb-pool"
  namespace = "capi"
  cluster   = capi_cluster.prod.name
  strategy  = "Reconcile"

  manifests = [
    yamlencode({
      apiVersion = "cilium.io/v2alpha1"
      kind       = "CiliumLoadBalancerIPPool"
      metadata   = { name = "tinkerbell" }
      spec       = { blocks = [{ start = "10.0.80.230", stop = "10.0.80.239" }] }
    }),
  ]

  prune = true
  wait  = { ready = true }

  depends_on = [capi_helm_chart_proxy.cilium]
}

# Registry credentials for every edge cluster, from a Secret the set
# references; applied once per cluster.
resource "capi_cluster_resource_set" "registry" {
  name             = "registry-credentials"
  namespace        = "capi"
  cluster_selector = { tier = "edge" }

  secrets = [
    yamlencode({
      apiVersion = "v1"
      kind       = "Secret"
      metadata   = { name = "registry", namespace = "kube-system" }
      type       = "kubernetes.io/dockerconfigjson"
      stringData = { ".dockerconfigjson" = var.registry_auth }
    }),
  ]
}
```

## Schema

### Required

- `name` (String) Object name; the ConfigMaps are `<name>-<index>` and the Secrets `<name>-secret-<index>`.

### Optional

- `cluster` (String) Apply to this one cluster (selects by its `cluster.x-k8s.io/cluster-name` label). Exclusive with `cluster_selector`. The selector is immutable.
- `cluster_selector` (Map of String) Apply to every Cluster in the namespace carrying these labels. Exclusive with `cluster`. Immutable.
- `manifests` (List of String) Multi-document YAML manifests, one ConfigMap each.
- `namespace` (String) Namespace, which the matched Clusters share. Default `default`.
- `prune` (Boolean) Delete objects that leave the set, and every object on destroy, from each matched cluster through its kubeconfig Secret. A cluster that is gone is skipped.
- `secrets` (List of String, Sensitive) Multi-document YAML manifests holding sensitive content, one Secret each.
- `strategy` (String) `ApplyOnce` (default: each resource is applied to a cluster once) or `Reconcile` (re-applied whenever its content changes). Immutable.
- `timeouts` (Attributes) (see [below for nested schema](#nestedatt--timeouts))
- `wait` (Attributes) What to wait for after an apply, within the operation's `timeouts`. (see [below for nested schema](#nestedatt--wait))

### Read-Only

- `conditions` (Attributes List) The object's conditions. (see [below for nested schema](#nestedatt--conditions))
- `id` (String) The ID of this resource.
- `manifest` (String) The applied ClusterResourceSet as YAML.
- `objects` (Attributes List) The objects the manifests define, in order: what `prune` tracks. (see [below for nested schema](#nestedatt--objects))
- `status` (Attributes) What each matched cluster's binding reports. (see [below for nested schema](#nestedatt--status))

## Import

Import is supported using the following syntax:

In Terraform v1.12.0 and later, the [`import` block](https://developer.hashicorp.com/terraform/language/import) can be used with the `identity` attribute, for example:

```terraform
import {
  to = capi_cluster_resource_set.lb_pool
  identity = {
    namespace = "capi"
    name      = "tinkerbell-lb-pool"
  }
}
```
