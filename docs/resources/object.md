# Object (Resource)

One object of an installed provider on the management cluster, server-side applied under this provider's field manager: the generic form of the typed object resources, for kinds they do not cover. `api_version` and `kind` name the object (take them from `data.capi_provider_components`); or give `kind` with `provider_type` and `provider_name` and the version is resolved from the installed CRDs at apply. Read compares every field `spec` sets against the live object; fields a controller owns never show as drift. Import with `kind:namespace/name`.

## Example Usage

```terraform
# Any object of an installed provider; the API version is resolved from its
# CRDs. Only the fields the configuration sets are compared on read.
resource "capi_object" "pool" {
  provider_type = "ipam"
  provider_name = "unifi"
  kind          = "UnifiIPPool"
  name          = "workers"
  namespace     = "capi"
  spec = {
    network = "10.0.80.0/24"
    ranges  = [{ start = "10.0.80.100", end = "10.0.80.200" }]
  }
  wait     = { conditions = ["Ready"] }
  timeouts = { create = "5m", update = "5m" }
}

# With an explicit API version.
resource "capi_object" "hardware" {
  api_version = "tinkerbell.org/v1alpha1"
  kind        = "Hardware"
  name        = "worker-1"
  namespace   = "capi"
  spec = {
    metadata = { instance = { hostname = "worker-1" } }
  }
}
```

## Schema

### Required

- `kind` (String) Kind.
- `name` (String) Object name.

### Optional

- `annotations` (Map of String) Annotations.
- `api_version` (String) `group/version`. Resolved from the management cluster's CRDs when unset and `provider_type`/`provider_name` are given.
- `force_conflicts` (Boolean) Take ownership of fields another field manager holds instead of failing on the conflict.
- `labels` (Map of String) Labels.
- `namespace` (String) Namespace. Default `default`; ignored for cluster-scoped kinds.
- `provider_name` (String) Provider name as clusterctl knows it.
- `provider_type` (String) With `provider_name`, the provider whose CRDs serve `kind`: `core`, `infrastructure`, `bootstrap`, `control_plane`, `ipam` or `addon`. Only needed when `api_version` is unset.
- `spec` (Dynamic) The object's `spec`, as an object with the CRD's camelCase keys.
- `timeouts` (Attributes) (see [below for nested schema](#nestedatt--timeouts))
- `wait` (Attributes) What to wait for after the object is applied. By default nothing is waited for. (see [below for nested schema](#nestedatt--wait))

### Read-Only

- `id` (String) The ID of this resource.
- `manifest` (String) The applied object as YAML.
- `status` (Dynamic) The object's `status`, as read.
- `uid` (String) The object's UID.

## Import

Import is supported using the following syntax:

In Terraform v1.12.0 and later, the [`import` block](https://developer.hashicorp.com/terraform/language/import) can be used with the `identity` attribute, for example:

```terraform
import {
  to = capi_object.pool
  identity = {
    kind      = "UnifiIPPool"
    namespace = "capi"
    name      = "workers"
  }
}
```
