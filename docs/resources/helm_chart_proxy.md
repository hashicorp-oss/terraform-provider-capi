# Helm Chart Proxy (Resource)

A Helm chart the addon provider for Helm (CAAPH) installs on every cluster `cluster_selector` matches, the way `aws_eks_addon` installs an addon on an EKS cluster: a `HelmChartProxy` on the management cluster the provider block names. CAAPH creates a `HelmReleaseProxy` per matched cluster and runs Helm through that cluster's kubeconfig Secret; `wait` watches those and, when one fails, quotes Helm's message and revision. Requires the `helm` addon provider on the management cluster. Import with `namespace/name`.

## Example Usage

```terraform
# Cilium on one cluster. The wait watches the HelmReleaseProxy CAAPH creates
# for the cluster and quotes Helm's message when the release fails.
resource "capi_helm_chart_proxy" "cilium" {
  name      = "cilium"
  namespace = "capi"
  cluster   = capi_cluster.prod.name

  chart = {
    name       = "cilium"
    repository = "oci://quay.io/cilium/charts"
    version    = "1.18.2"
  }

  release = {
    name      = "cilium"
    namespace = "kube-system"
    values    = file("${path.module}/cilium-values.yaml")
  }

  options = {
    wait    = true
    timeout = "10m"
  }

  wait = { timeout = "15m" }
}

# cert-manager on every cluster labelled tier=edge, installed once and then
# left alone. Values may template over the matched Cluster.
resource "capi_helm_chart_proxy" "cert_manager" {
  name             = "cert-manager"
  namespace        = "capi"
  cluster_selector = { tier = "edge" }
  strategy         = "InstallOnce"

  chart = {
    name       = "cert-manager"
    repository = "https://charts.jetstack.io"
    version    = "v1.17.0"
  }

  release = {
    name      = "cert-manager"
    namespace = "cert-manager"
    values    = <<-EOT
      crds:
        enabled: true
      global:
        commonLabels:
          cluster: {{ .Cluster.metadata.name }}
    EOT
  }

  options = {
    install = { create_namespace = true }
  }

  force_delete = true
}
```

## Import

Import is supported using the following syntax:

In Terraform v1.12.0 and later, the [`import` block](https://developer.hashicorp.com/terraform/language/import) can be used with the `identity` attribute, for example:

```terraform
import {
  to = capi_helm_chart_proxy.cilium
  identity = {
    namespace = "capi"
    name      = "cilium"
  }
}
```
