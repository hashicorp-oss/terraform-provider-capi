# CAPI Provider

Manages Cluster API clusters, their objects and their providers through clusterctl's own libraries. The provider block names the management cluster, the way the aws provider block names the AWS API: `kubeconfig` (content, typically an ephemeral `capi_kubeconfig`), or the `kubernetes` block with a config path and context, or a host and credentials. A `capi_cluster` that bootstraps its own management cluster needs neither.

The provider manages [Cluster API](https://cluster-api.sigs.k8s.io) clusters
through clusterctl's own libraries, the way the `aws` provider manages EKS:

- The provider block names the **management cluster**.
- `capi_cluster` is the cluster: identity, version, network, control plane and
  waits. With `management.self_managed` it also stands up its own management
  cluster through a disposable bootstrap cluster and pivots into itself.
- Every other Cluster API object is its own resource: node groups
  (`capi_machine_deployment`), launch-template-style revisions
  (`capi_machine_template`, `capi_control_plane_template`,
  `capi_bootstrap_template`), classes, health checks, addons
  (`capi_helm_chart_proxy`, `capi_cluster_resource_set`), Tinkerbell hardware
  and clusterctl providers.

## Example Usage

```terraform
# The management cluster, through a kubeconfig file and context.
provider "capi" {
  kubernetes = {
    config_path    = "~/.kube/config"
    config_context = "mgmt"
  }
}

# Or kubeconfig content, typically an ephemeral capi_kubeconfig.
provider "capi" {
  alias      = "content"
  kubeconfig = file("~/.kube/mgmt.kubeconfig")
}
```

## Reaching a self-managed cluster

A cluster that manages itself has no other management cluster to name in the
provider block. Derive a kubeconfig from the root credential the pivot
captured, with an ephemeral resource, so it never enters state:

```terraform
ephemeral "capi_kubeconfig" "self" {
  cluster  = capi_cluster.mgmt.name
  secrets  = capi_cluster.mgmt.provider_secrets
  endpoint = capi_cluster.mgmt.status.endpoint
  ttl      = "8h"
}

provider "capi" {
  alias      = "self"
  kubeconfig = ephemeral.capi_kubeconfig.self.raw
}
```

## Timeouts and waits

Every resource takes `timeouts = { create, update, delete }` as Go durations
(`10m` by default; `capi_cluster` allows `2h` to create and delete, `60m` to
update). Resources that wait for readiness name the conditions in
`wait = { conditions = [...] }`; the wait gets whatever is left of the
operation's timeout.

## Import

Every resource can be imported by ID (`terraform import`, or an `import`
block with `id`) and, with Terraform 1.12 or later, by `identity`. A
`capi_cluster` that stopped mid-create keeps its progress in private state, so
the next apply resumes it rather than starting over.

- `kubeconfig` (String, Sensitive) Kubeconfig content of the management cluster. Feed it from an ephemeral `capi_kubeconfig` so it never enters state. Takes precedence over `kubernetes`.
- `kubernetes` (Attributes) Kubernetes connection to the management cluster, with the attributes of the `kubernetes` provider: `config_path`/`config_paths` with `config_context*`, or `host` with a token, a client certificate or basic auth. `KUBE_CONFIG_PATH` and `KUBE_CONFIG_PATHS` are read when neither is set. ### Nested Schema for `kubernetes`

Optional:

- `client_certificate` (String) PEM-encoded client certificate for TLS authentication
- `client_key` (String, Sensitive) PEM-encoded client certificate key for TLS authentication
- `cluster_ca_certificate` (String) PEM-encoded root certificates bundle for TLS authentication
- `config_context` (String) Context to choose from the config file
- `config_context_auth_info` (String) Authentication info context of the kube config (name of the kubeconfig user, --user flag in kubectl)
- `config_context_cluster` (String) Cluster context of the kube config (name of the kubeconfig cluster, --cluster flag in kubectl)
- `config_path` (String) Path to the kube config file. Can be set with KUBE_CONFIG_PATH environment variable
- `config_paths` (List of String) A list of paths to kube config files. Can be set with KUBE_CONFIG_PATHS environment variable
- `host` (String) The hostname (in form of URI) of the Kubernetes master
- `insecure` (Boolean) Whether server should be accessed without verifying the TLS certificate
- `password` (String, Sensitive) The password to use for HTTP basic authentication when accessing the Kubernetes master endpoint
- `proxy_url` (String) URL to the proxy to be used for all API requests
- `tls_server_name` (String) Server name passed to the server for SNI and is used in the client to check server certificates against
- `token` (String, Sensitive) Token to authenticate a service account
- `username` (String) The username to use for HTTP basic authentication when accessing the Kubernetes master endpoint
